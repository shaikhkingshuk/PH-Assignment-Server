# HomenestBD (Server)

HomenestBD Server is the backend part of a full-stack real estate web application
developed as a course project. It provides RESTful APIs to handle property data,
user interactions, and review management for the client application.

🌐 Server Base URL: https://homenest-server.onrender.com

---

## 🚀 Features

- RESTful APIs for property listings (add, read, update, delete)
- APIs for buying and renting property-related data handling
- Review and comment management endpoints
- Secure API access with Firebase token verification
- Structured backend using Express and Node.js

---

## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- Firebase Admin SDK
- Render (Deployment)

---

## 📌 Project Purpose

This server-side application was built to practice backend development concepts,
REST API design, database operations, authentication verification, and deployment
using cloud platforms.
